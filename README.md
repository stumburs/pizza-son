## AI-assisted development

AI was used during the development of `pizza-son` as a development aid. However, this project was not created by simply asking an AI to "make me a Twitch bot" and accepting the resulting code.

AI was used more like a **junior developer**: I provided explicit instructions about what I wanted to create, how I wanted it implemented, which libraries, technologies, and approaches to use, and how the resulting code should fit into the existing project. The generated code was then thoroughly analyzed, tested, and reviewed by me before being used.

Parts of AI-generated code were also manually rewritten, refactored, or replaced when they did not match my intentions, coding style, architecture, or requirements. The final implementation is therefore the result of human-directed development with AI assistance, rather than an unreviewed AI-generated project.
